# Our Japan Days

## Preview in VS Code

1. Open this entire folder in VS Code using File → Open Folder.
2. Right-click index.html and choose Open with Live Server.
3. Keep the assets folder beside index.html.

Go Live previews on your computer; it does not publish to GitHub.

## Publish with GitHub Pages

1. Upload this folder’s contents to your repository root: index.html, assets/, and .nojekyll. Do not upload only the ZIP or nest everything inside another folder.
2. Open repository Settings → Pages.
3. Choose Deploy from a branch, select main and / (root), then Save.
4. Wait for deployment to finish and use the site link shown in Pages settings.

No install or build step is required. The photos are hosted alongside the page.
